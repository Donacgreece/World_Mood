# Moodaro brand direction

## Core idea
Moodaro turns anonymous real-world feelings into a playful live social pulse.

## Brand line
**Feel the world together.**

## Supporting message
**Real people. Real feelings. A brighter tomorrow.**

## Visual system
- Primary violet: `#6F55FF`
- Sky blue: `#4B84FF`
- Cyan: `#2ED7F2`
- Social pink: `#FF68C8`
- Midnight text: `#101731`
- Cloud background: `#F5F7FF`

The primary mark is a smiling location-pin mascot. The same core character is used in the site logo, favicon, PWA icon and splash experience.

## Product tone
Friendly, optimistic, playful and social-first. Moodaro should feel expressive without becoming childish, and polished without becoming corporate.
